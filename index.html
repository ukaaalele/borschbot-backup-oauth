BorschBOT Backup

A personal backup utility operated by the owner of this repository. It uses rclone to save and restore private backup archives in the owner's Google Drive.

This is an OAuth application information page. It contains no bot source code, backup contents, credentials, or user records.

The application requests only drive.file: access to files created by or explicitly opened with this application, rather than all files in Google Drive.

Privacy policy

Last updated: 27 October 2026.

This application is for the owner's personal backup use. It is not a public sign-up service. Google authorization is used to access the permitted backup files in the owner's Google Drive.

Backup archives may contain private application configuration and application data. They are stored in the owner's private Google Drive and on machines controlled by the owner. They are not published in this repository. Google processes stored files under its own policies.

OAuth tokens and client credentials are stored in private local configuration used by rclone. They are not included in the public documentation. Backup data is not sold, used for advertising, or shared with unrelated third parties.

The owner controls backup retention and deletion. Access can be revoked in the Google Account connections settings; revocation does not automatically delete existing backup files. The owner can delete those files separately in Google Drive.

Do not submit passwords, tokens, backup files, or private bot data to public issues. Public issues are only for non-sensitive questions about this application.

Terms of use

This utility is intended solely for personal use by its operator. It is provided without guarantees of availability or recovery. The operator is responsible for access controls, retention, and testing restoration. No public backup service is offered.
